## Description
A number guessing game where the player tries to guess a random number between 1 and 20.

## Input
The player types whole numbers between 1 and 20.

## Output
The program says "Too low!" or "Too high!" after each guess, then reports how many tries it took when the player guesses correctly.

## How to run
1. Install Python 3.
2. Open a terminal in this folder.
3. Run: `python3 myProgram.py`
